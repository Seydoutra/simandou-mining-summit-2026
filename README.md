# Simandou Mining Summit 2026

Version statique prête pour GitHub Pages.

## Publication

Créer un dépôt GitHub, copier le contenu de ce dossier à sa racine, puis pousser la branche `main`. Le workflow `.github/workflows/pages.yml` publie automatiquement le site. Dans les réglages du dépôt : **Settings → Pages → Source: GitHub Actions**.

Les routes localisées existent comme dossiers réels (`/fr/`, `/en/`, `/zh/`) et ne dépendent pas de la règle Netlify `_redirects`. Les assets utilisent des chemins absolus, donc la publication fonctionne sur une URL de projet GitHub Pages.


Pages source: GitHub Actions.
